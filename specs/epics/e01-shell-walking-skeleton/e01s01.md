## 5. Main flow and business logic [locked]

1. Squash-merge one `chore:` commit (footer schema sync preview) to `main`.
2. TBR runs; big-release writes VERSION and tag from commit type.
3. CI job `preflight` → `build` → `deploy` → `smoke`.
4. Visitor loads https://127.0.0.1:8765/; UI shows VERSION from release artifact.

**Interruption point:** preflight fails → deploy job skipped.
